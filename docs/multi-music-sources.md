# 多音乐接口升级

支持内置原接口和多个 ShyMusic v2 协议实例，自定义名称、公网地址、密钥和独立启停。未知协议并非自动兼容。ShyMusic仅支持网易云，QQ/酷狗与歌单导入保留原接口。关闭来源不自动回退，已有歌曲仍可保留和排序。暂不提供删除接口，避免歌曲引用失效。

## 部署
1. 备份数据库和 storage 配置目录，暂停歌单编辑。
2. 同步完整代码，勿覆盖已有 storage 配置，确认 PHP cURL 和数据库 ALTER 权限。
3. 项目根目录执行 `php scripts/upgrade_music_source.php`。禁止导入 install.sql 到旧数据库。
4. 清除框架缓存及浏览器播放器脚本缓存。
5. 高级设置添加/编辑接口，在歌单选择来源搜索、试听、添加、保存并刷新。验证两个来源混合播放/歌词，以及关闭其中一个后另一个正常。

## 兼容和限制
旧歌曲缺省 legacy。上一版 ShyMusic 配置可迁移到 shy_migrated，但上一版添加歌曲未记录来源，不能自动判断归属，应重新从目标接口添加。接口名称变化不改变固定来源 ID。
密钥服务器端明文文件权限0600，不返回页面；HTTP传输有泄露风险，优先确认可用HTTPS并轮换已暴露密钥。自定义服务必须遵守ShyMusic v2协议，当前只接收网易云 music.126.net 音频域名。

保存采用先插入新记录、再删除旧记录降低MyISAM写入失败丢歌风险，不具备事务原子性；不要同时编辑同一歌单或同时修改接口配置。无真实线上数据库迁移、登录保存和音频播放验收证据，部署后必须执行以上验收。
